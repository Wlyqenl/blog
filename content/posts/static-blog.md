# 用纯静态方式，搭一个真正属于你的博客

很多人想写博客，却被「要装什么环境」「要买什么服务器」劝退。其实，一个好看、能渲染 Markdown、还能离线打开的博客，用最朴素的几份文件就能搞定。

## 为什么选纯静态

不需要数据库，不需要后端，不需要登录服务器。一份 `index.html`、一份样式、几篇 `.md` 文章，双击就能在浏览器里打开。

> 写作的本质是表达，而不是和工具搏斗。

静态博客的好处很直接：

- **零运维**：没有服务器要养，没有依赖要升级
- **可携带**：整个文件夹拷到任何地方都能跑
- **够快**：没有查询，没有渲染延迟，打开即所见

## 核心就三块

一个最小可用的博客，通常只需要下面三块：

1. **文章数据**：每篇文章的标题、标签、日期和正文
2. **渲染逻辑**：把 Markdown 变成网页能显示的 HTML
3. **页面骨架**：列表、详情、标签页、关于页

```js
// 一段极简的 Markdown 渲染示意
function render(markdown) {
  return markdown
    .replace(/^# (.*)$/gm, '<h1>$1</h1>')
    .replace(/\*\*(.*?)\*\*/g, '<strong>$1</strong>');
}
```

当然，真实项目里我们会用一个更完整的解析器来处理列表、表格、代码块——这正是这个小博客在做的事。

## 写在最后

你不需要等到「工具有多完美」才开始写。先有一块能落笔的地方，剩下的，边写边改就好。

| 方式 | 门槛 | 适合谁 |
| --- | --- | --- |
| 纯静态 | 低 | 想专注写作的人 |
| 框架生成 | 中 | 喜欢折腾的开发者 |
| 平台托管 | 低 | 不想碰代码的人 |

愿你的第一篇文章，很快就写下来。
